# Светлая сторона: честный разбор и план

Октябрь 2026. Статус — демо: проверяем, нужно ли это людям. Если зайдёт — вкладываться. Монетизация заложена в архитектуру (аналитика, бесплатный отчёт как будущий платный продукт), но не строится. Бюджет 0 ₽, хостинг пока Vercel.

## Вердикт

**Сильное**
- Прямого бесплатного сервиса «сколько солнца в окне квартиры по адресу» на русском и с российской нормой не нашли.
- Расчёт настоящий (трассировка лучей по 3D-кварталу), вау-эффект есть.
- Спрос косвенно подтверждён:
  - девелоперы берут +2–3% цены за южную сторону (dp.ru, 11.2025);
  - Shadowmap встроили в объявления Redfin (05.2026) и австрийского willhaben. По данным самого Shadowmap, на willhaben это дало +10,7% заявок.

**Слабое — пока это красивая игрушка, а не продукт**
1. Главный вопрос покупателя — «какую квартиру в этом доме брать». Сейчас ответ требует перебирать окна; нужна матрица «этажи × стороны» (этап 2).
2. Новостройки — главный сценарий — покрыты плохо: строящихся домов часто нет в OSM, этажность бывает неверной.
3. Источник данных (OSM API) нельзя масштабировать: правила это запрещают, на всплеске трафика будут 429.
4. `*.vercel.app` в РФ частично блокируется; бесплатный Vercel — только некоммерческий.
5. Демо никто не видел: аналитики до этапа 1 не было.

**Исправлено на этапе 1**
- Норма: отсечка 1 ч южнее 58° и 1,5 ч севернее (раньше было наоборот).
- Лоджия и балкон выше.
- Вердикт и «сколько забирают соседи».
- Выбор стороны дома кнопками.
- Отрисовка только при изменениях, уровни качества под слабые ПК, расчёт в Web Worker.
- Тесты и CI, Метрика (ждёт номер счётчика).

## Этап 2 — до любого продвижения
1. ✅ **Матрица дома:** этажи × стороны, часы солнца в год, отметка нормы.
2. ✅ **«Достроить / поправить дом»:** контур строящегося соседа и его этажность, сохраняется в ссылке.
3. ✅ **Свои данные вместо OSM API:** публичный репозиторий тайлов `svetlaya-storona-data`.
   - GitHub Actions раз в месяц: выгрузка Geofabrik → здания Москвы и Петербурга → тайлы.
   - Раздача через GitHub Pages.
   - Сайт сначала берёт тайлы, OSM API — только для непокрытых городов.
4. ✅ **Отчёт:** картинка для мессенджеров и PDF через `window.print`. Бесплатно; клики — цели `report_image` и `report_pdf`. Это и есть проверка спроса на будущий платный отчёт.
5. ◐ **Проверка точности** — `docs/ACCURACY.md`. Найдено расхождение в счёте восхода с инсоляционными графиками (5% окон), такие окна помечены «на грани». Сверки с реальным расчётом ЖК пока нет: в открытом доступе не нашли. Нужен PDF от проектировщика или застройщика.

## Этап 3 — показать людям и измерить отклик (0 ₽)

**Каналы:**
1. Чаты дольщиков конкретных ЖК (Telegram, VK) — готовые разборы: «какие стояки корпуса 3 теряют солнце из-за корпуса 5».
2. Хабр — техническая статья (только после тайлов, иначе OSM API ляжет).
3. VC.ru / Дзен — «Застройщики берут +2–3% за солнечную сторону — проверил, получаете ли вы её».
4. 5–10 приёмщиков квартир и риелторов — за честной обратной связью, не за продажей.
5. SEO-страницы ЖК — это уже вложения, если демо зайдёт.

**Как решаем, вкладываться ли** (сверить с Метрикой):
- **Зашло:** ≥100 пользователей в неделю из бесплатных каналов, ≥30% ставят окно, люди скачивают отчёты (`report_pdf`, `report_image`) и пишут «а можно для моего ЖК».
- **Не зашло:** после этапа 2 и двух публикаций за 6–8 недель цифры заметно ниже. Тогда проект остаётся портфолио, или пробуем узко B2B.

## Заложено на потом (сейчас не делаем)
- **Оплата:** самозанятость (НПД), ЮKassa или Robokassa. Перед этим — переезд с Vercel Hobby на Yandex Object Storage и Cloud Functions (почти 0 ₽ в бесплатном лимите).
- **Платные отчёты:** PDF за ~500 ₽ для частных лиц, B2B-отчёты под брендом приёмщиков и риелторов.
- **Порталы** (ЦИАН, Домклик) — только с цифрами на руках.
