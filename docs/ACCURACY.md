# Точность расчёта: что проверено

Октябрь 2026.

## Сравнение с реальным заключением — пока не сделано

Хотели сверить расчёт с разделом «Расчёт инсоляции» из проектной документации реального ЖК. Не получилось. В открытом поиске нашлись только нормы и учебные пособия. Расчётов по конкретным окнам там нет. На наш.дом.рф выкладывают проектную декларацию и заключение экспертизы. В заключениях обычно сказано «инсоляция обеспечивается», без минут по окнам.

**Что нужно для настоящей сверки:**
- PDF раздела АР или отчёт Insolaris / «Соляриса» с расчётными точками. Такой могут дать знакомый проектировщик или застройщик, иногда он лежит на сайте ЖК в разделе «Документы».
- Для каждой точки: дом, этаж, сторона, минуты на 22 апреля.
- Нужен квартал, который есть в OpenStreetMap с правильными высотами.

## Найдено и исправлено: как считать начало и конец дня

ГОСТ Р 57795-2017 (п. 5.7): южнее 58° с.ш. первый час после восхода и последний час перед заходом не учитываются. Приложение берёт точный восход: на 22 апреля в Москве он в 4:48 по солнечному времени, учитывается 5:48–18:12. Инсоляционные графики, которые ГОСТ тоже разрешает (п. 5.2), округляют восход до часа: для 55° с.ш. учитывается 6:00–18:00. Так считают по пособию МАрхИ (Поповский) и на графиках для Москвы.

**Разница — 12–13 минут с каждой стороны дня.** Она важна только для окон, у которых солнце бывает утром или вечером.

**Проверка на демо-квартале у Москва-Сити:** 354 окна жилых домов, по 3 этажа на каждый фасад длиннее 10 м.

| | Окон |
|---|---|
| Проходят норму по точному восходу | 216 |
| Из них не проходят по инсоляционному графику | 18 (5,1% всех окон) |
| Проходят по графику, но не по точному восходу | 0 |

Ошибка только в одну сторону: точный восход делает приложение мягче графика. Поэтому такие окна теперь помечены «На грани нормы». Это видно в карточке нормы, кольцом в матрице дома, в картинке и в PDF. Решать, какой способ верный, приложение не берётся: проектировщики считают обоими способами.

## Известные расхождения внутри приложения

- **Матрица дома и основной расчёт.** Матрица считает каждые 4 дня с шагом 15 минут, основной расчёт — каждый день с шагом 10 минут. Расхождение по часам в год — до 2–3%. Пример: 1 140 ч против 1 135 ч в демо-окне.
- **Норма в матрице** считается так же точно, как в основном расчёте: один день, шаг 1 минута.

## Что не учитывается

- Деревья, рельеф, отражённый свет.
- Точные размеры окна и откосов: расчётная точка стоит в центре окна. Солнце, которое идёт вдоль стены под углом меньше 10°, не считается.
- Лоджия и балкон — упрощённой коробкой: глубина задаётся, ширина 3 м, плита на 1,3 м выше центра окна.
- Высоты домов взяты из OpenStreetMap. Если этажность не указана, она угадана по типу здания и показана как «угадана». Строящихся домов в OSM часто нет — их нужно дорисовать.
