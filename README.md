# Светлая сторона

Сколько прямого солнца получит окно квартиры — по любому адресу, в 3D.

Найдите дом, кликните по стене там, где окно, и сайт посчитает солнце на каждый день года:
часы прямого солнца, солнечный календарь, какие дома его закрывают, ориентир по норме инсоляции
СанПиН 1.2.3685-21 и матрицу всего дома «этажи × стороны». Строящийся дом, которого нет на карте,
можно дорисовать. Результат — картинка для мессенджера или PDF-отчёт.

## Как устроено

Статический сайт без сборки: `index.html`, `css/`, `js/` (ES-модули), three.js с CDN.

- `js/tiles.js` — загрузка квартала из своих тайлов (репозиторий `svetlaya-storona-data` на GitHub Pages), запасной путь — OpenStreetMap API
- `js/osm.js`, `js/osm-rules.js`, `js/tile-format.js` — разбор данных OSM в модель квартала, формат тайлов
- `js/sun.js` — положение солнца, часовые пояса
- `js/insolation.js` — трассировка лучей от окна к солнцу, календарь, норма, этажи
- `js/scene.js` — 3D-сцена (three.js)
- `js/report.js` — картинка для мессенджеров и PDF-отчёт (печать браузера)
- `js/main.js` — интерфейс и связка всего вместе
- `data/demo.json` — демо-квартал у Москва-Сити (© участники OpenStreetMap, ODbL)

## Проверка

- Тесты (без зависимостей): `node --test tests/*.test.mjs`. Их же запускает GitHub Actions на каждый пуш.
- `?debug=1` — счётчик кадров, уровень качества, цели аналитики в консоли.
- `?q=low|mid|high` — принудительный уровень качества 3D.

## Настройки

`js/config.js`: номер счётчика Яндекс Метрики (`metrikaId`, пока `null` — аналитика выключена) и адрес тайлов (`dataUrl`).

## Локальный запуск

ES-модули не грузятся с `file://`, поэтому нужен любой локальный сервер:

```bash
python -m http.server 5173
```

и открыть http://localhost:5173.

Версия одним файлом, которая открывается двойным кликом: `node tools/build-standalone.mjs` → `dist/index.html`.

## Данные

- Дома, дороги, парки — OpenStreetMap. Москва и Петербург — из своих тайлов, которые раз в месяц собирает репозиторий [svetlaya-storona-data](https://github.com/z1mo0x/svetlaya-storona-data); остальные города — из OSM API (его правила не разрешают массовую нагрузку, поэтому покрытие тайлами надо расширять).
- Поиск адресов — Photon (komoot).
- Расчёт ориентировочный и не заменяет официальный расчёт по ГОСТ Р 57795-2017.
