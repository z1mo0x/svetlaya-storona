# Полдень

Сколько прямого солнца получит окно квартиры — по любому адресу, в 3D.

Найдите дом, кликните по стене там, где окно, и сайт посчитает солнце на каждый день года:
часы прямого солнца, солнечный календарь, какие дома его закрывают, сравнение этажей
и ориентир по норме инсоляции СанПиН 1.2.3685-21.

## Как устроено

Статический сайт без сборки: `index.html`, `css/`, `js/` (ES-модули), three.js с CDN.

- `js/osm.js` — загрузка домов из OpenStreetMap API и разбор в модель квартала
- `js/sun.js` — положение солнца, часовые пояса
- `js/insolation.js` — трассировка лучей от окна к солнцу, календарь, норма, этажи
- `js/scene.js` — 3D-сцена (three.js)
- `js/main.js` — интерфейс и связка всего вместе
- `data/demo.json` — демо-квартал у Москва-Сити (© участники OpenStreetMap, ODbL)

## Локальный запуск

ES-модули не грузятся с `file://`, поэтому нужен любой локальный сервер:

```bash
python -m http.server 5173
```

и открыть http://localhost:5173.

Версия одним файлом, которая открывается двойным кликом: `node tools/build-standalone.mjs` → `dist/index.html`.

## Данные

- Дома, дороги, парки — OpenStreetMap API (для продакшена нужен свой сервер данных: правила OSM не разрешают нагружать этот API массовыми запросами).
- Поиск адресов — Photon (komoot).
- Расчёт ориентировочный и не заменяет официальный расчёт по ГОСТ Р 57795-2017.
